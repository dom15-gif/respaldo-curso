# Farmacia Comandiu

Este repositorio está organizado en dos carpetas separadas:

- `frontend/` — Código de la aplicación React/Vite.
- `backend/` — Código del servidor Express.

## Cómo usar

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Esto inicia la aplicación React en modo de desarrollo.

### Backend

```bash
cd backend
npm install
npm run dev
```

Esto inicia el servidor Express en `http://localhost:4000`.

## Estructura de carpetas

- `frontend/src/` — código React principal.
- `frontend/src/components/` — componentes separados por sección.
- `frontend/public/` — archivos estáticos del frontend.
- `backend/server.js` — servidor Express.

## Notas

- Los formularios y las vistas se manejan en el frontend.
- El backend tiene rutas de ejemplo para `clientes`, `productos` y `contacto`.
- Puedes agregar tus propias imágenes dentro de los componentes en `frontend/src/components/`.
